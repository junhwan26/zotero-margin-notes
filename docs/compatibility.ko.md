# 의존성·호환성 검사 기록

[English](compatibility.md)

**확인 날짜: 2026-10-08 · 여백 노트 0.3.0 · Zotero 9.0.6 / 10.0.6 · macOS**

여백 노트는 Zotero 9.0부터 10.0.*까지 지원하도록 선언합니다. **다른 Zotero 플러그인이나 npm 런타임 패키지를 요구하지 않습니다.** 구현은 배포 XPI에 포함되어 있고 코멘트는 Zotero 주석에 저장합니다.

이 문서는 의존성 확인, 자동 회귀 검사, 로컬 Zotero 9와 Zotero 10 환경에서 관찰한 플러그인 활성화 상태를 기록합니다. 함께 활성화되어 있다는 사실만으로 다른 플러그인의 모든 기능을 검사했다고 볼 수는 없습니다.

## 의존성 확인

| 구성 요소 | 사용에 필요한가? | 근거 |
| --- | --- | --- |
| Zotero 9.0-10.0.* | 필요 | [지원 버전 선언](../manifest.json). CI는 Zotero 9.0.6과 10.0.6으로 구성되어 있습니다. |
| 다른 Zotero 플러그인 | 불필요 | [manifest](../manifest.json)와 [bootstrap](../bootstrap.js)에 필수 플러그인 선언이나 로딩이 없습니다. |
| npm 런타임 패키지 | 불필요 | [package.json](../package.json)에 런타임 의존성이 없으며 [빌드](../scripts/build.py)는 프로젝트 소스를 묶습니다. |
| Node.js·Python 3 | 개발에만 필요 | 검사와 XPI 생성에 사용합니다. 사용자는 XPI를 바로 설치합니다. |

bootstrap은 포함된 언어·배치·표시 스크립트를 불러오고, 타이머는 Zotero의 Gecko 내장 모듈을 사용합니다. 코멘트를 표시하거나 편집하기 위해 별도 외부 서비스를 이용할 필요는 없습니다. Zotero의 일반 주석 동기화와 GitHub 플러그인 업데이트는 사용할 수 있습니다.

Zotero 공식 [Zotero 10 for Developers](https://www.zotero.org/support/dev/zotero_10_for_developers) 문서는 호환성을 확인한 뒤 `strict_max_version`을 `10.0.*`로 올리라고 안내합니다. Zotero [버전 기록](https://www.zotero.org/support/changelog)은 Zotero 10.0.6이 2026-10-07에 릴리스되었다고 기록합니다.

실제 Zotero 검사는 텍스트 선택 팝업, 하이라이트, 밑줄, 사이드바·여백 코멘트 편집, 더블클릭, 블록 선택 표시, 두 테마의 흰색 노트, 삭제, 실행 취소·다시 실행, 검색, 확대·축소, 페이지 이동과 PDF 재열기 후 저장 상태를 확인합니다. 복사 검사는 가상 이벤트로 PDF 텍스트 변환을 검사하며 운영체제의 공용 클립보드를 사용하지 않습니다.

**자동 Zotero 검사 환경에는 아래의 다른 플러그인을 설치하지 않았습니다.** 여백 노트의 독립 동작과 검사에 포함된 기본 리더 동작을 확인한 것이며, 다른 플러그인 조합의 호환성 인증은 아닙니다.

## 다른 플러그인과 함께 활성화된 환경

2026-10-08 실제 Zotero 10.0.6 UI에서 여백 노트 0.3.0이 활성화된 상태로 아래 버전을 확인했습니다. **설치·활성화 상태 관찰**이며, 개별 플러그인의 전체 기능을 검사한 결과는 아닙니다.

| 플러그인 | 확인 버전 | 관찰 결과 | 여백 노트의 필수 의존성인가? |
| --- | --- | --- | --- |
| Better BibTeX for Zotero | 9.0.70 | 여백 노트 0.3.0과 함께 활성화됨. 전체 기능 검사는 수행하지 않았습니다. | 아니요 |
| Translate for Zotero | 2.4.8 | 여백 노트 0.3.0과 함께 활성화됨. 전체 기능 검사는 수행하지 않았습니다. | 아니요 |
| Ethereal Style | 6.0.86 | 여백 노트 0.3.0과 함께 활성화됨. 전체 기능 검사는 수행하지 않았습니다. | 아니요 |
| Research Vault Bridge | 0.2.0 | 비활성 상태. Zotero 9 전용이라 Zotero 10과 호환되지 않는 것으로 관찰했습니다. | 아니요 |

2026-10-07 Zotero 9.0.6 시기 관찰 기록: Better BibTeX 9.0.70, Translate for Zotero 2.4.8, Ethereal Style 6.0.86, Research Vault Bridge 0.2.0은 여백 노트 0.2.3과 함께 활성화되어 있었고, ZotMoov 1.2.32는 설치되어 있었지만 비활성 상태였습니다. 이 기록은 Zotero 10 호환성으로 재분류하지 않습니다.

## 지원 범위와 미검증 영역

- 선언한 지원 버전은 Zotero **9.0-10.0.\***이며 자동 검사 버전은 **9.0.6**과 **10.0.6**입니다.
- PDF 리더에만 적용합니다. EPUB와 웹 스냅샷은 건너뜁니다.
- 로컬 실제 Zotero 검사는 macOS에서 실행했습니다. Windows와 Linux는 이 검사에 포함하지 않았습니다.
- Zotero 10 읽기 모드는 PDF iframe을 읽기 화면 아래에 유지합니다. Margin Notes 0.3.0은 해당 화면을 멈춰서 카드가 읽기 모드를 가리지 않게 하고, Fit Notes가 숨은 PDF 화면을 확대/축소하지 않게 합니다. 자동 회귀 검사는 실제 PDF 리더의 읽기 모드 상태와 PDF 화면의 표시 여부를 통해 이 동작을 확인하며, 별도 읽기 모드 화면 전체를 조작하는 검사는 아닙니다.
- PDF 리더의 내부 주석·화면 위치 API를 사용하고 텍스트 초점 처리 함수를 일시적으로 확장합니다. 같은 내부 함수나 PDF 리더 스타일을 바꾸는 다른 플러그인은 조합별 확인이 필요합니다. 특정 플러그인과 함수 래퍼가 겹치는 경우의 자동 검사는 아직 없습니다.

상호작용 문제가 발생하면 Zotero 버전, 여백 노트 버전, 다른 플러그인 이름·버전, 읽기 모드 활성 여부와 재현 절차를 [이슈](https://github.com/junhwan26/zotero-margin-notes/issues/new)에 적어 주세요. 여백 노트를 끈 상태에서도 문제가 발생하는지 함께 적으면 원인을 확인하는 데 도움이 됩니다.

## 개발 검사

```sh
npm test
npm run check
npm run build
```

실제 Zotero 검사 도구는 자체 프로필·라이브러리·합성 PDF를 생성하고 정리합니다. 사용자의 기존 라이브러리를 검사하거나 사용자 프로필의 다른 플러그인을 가져와 설치하지 않습니다. CI는 공식 Zotero DMG를 내려받고 SHA-256을 확인한 뒤 Zotero 9.0.6과 Zotero 10.0.6 각각에서 실제 앱 검사를 한 번씩 실행합니다. 설정 세부 내용은 [runtime-test-notes.md](runtime-test-notes.md)를 참고하세요.
