# 의존성·호환성 검사 기록

[English](compatibility.md)

**확인 날짜: 2026-10-07 · 여백 노트 0.2.3 · Zotero 9.0.6 · macOS**

여백 노트는 Zotero 9.0.x가 필요하며, **다른 Zotero 플러그인이나 npm 런타임 패키지를 요구하지 않습니다.** 구현은 배포 XPI에 포함되어 있고 코멘트는 Zotero 주석에 저장합니다.

이 문서는 의존성 확인, 자동 회귀 검사, 한 로컬 환경에서 관찰한 플러그인 활성화 상태를 기록합니다. 함께 활성화되어 있다는 사실만으로 다른 플러그인의 모든 기능을 검사했다고 볼 수는 없습니다.

## 의존성 확인

| 구성 요소 | 사용에 필요한가? | 근거 |
| --- | --- | --- |
| Zotero 9.0.x | 필요 | [지원 버전 선언](../manifest.json). 실제 검사 기준은 Zotero 9.0.6입니다. |
| 다른 Zotero 플러그인 | 불필요 | [manifest](../manifest.json)와 [bootstrap](../bootstrap.js)에 필수 플러그인 선언이나 로딩이 없습니다. |
| npm 런타임 패키지 | 불필요 | [package.json](../package.json)에 런타임 의존성이 없으며 [빌드](../scripts/build.py)는 프로젝트 소스를 묶습니다. |
| Node.js·Python 3 | 개발에만 필요 | 검사와 XPI 생성에 사용합니다. 사용자는 XPI를 바로 설치합니다. |

bootstrap은 포함된 언어·배치·표시 스크립트를 불러오고, 타이머는 Zotero의 Gecko 내장 모듈을 사용합니다. 코멘트를 표시하거나 편집하기 위해 별도 외부 서비스를 이용할 필요는 없습니다. Zotero의 일반 주석 동기화와 GitHub 플러그인 업데이트는 사용할 수 있습니다.

## 완료한 검사

| 검사 | 결과 | 확인 범위 |
| --- | --- | --- |
| 실제 Zotero 회귀 검사 | **218 / 218 통과** | Zotero 9.0.6, 합성 두 단 PDF, 임시 프로필과 별도 검사 라이브러리. |
| Node 검사 | **23 / 23 통과** | 배치, 다국어, 시작·종료, 패키징 계약. |
| 다른 도구막대 리스너 보존 | **통과** | 시작·종료를 반복해도 가상의 `another-plugin` 리스너를 보존합니다. 특정 플러그인을 실행하는 통합 검사는 아닙니다. |
| 종료 후 기본 리더 복원 | **통과** | 여백 노트와 도구막대 제거, 원래 초점 처리 함수 복원, 기본 PDF 텍스트 선택 재검사. |
| 배포 파일 일치 | **통과** | 공개 XPI, 설치 XPI, 검사한 빌드의 SHA-256이 같습니다. |

실제 Zotero 검사는 텍스트 선택 팝업, 하이라이트, 밑줄, 사이드바·여백 코멘트 편집, 더블클릭, 블록 선택 표시, 두 테마의 흰색 노트, 삭제, 실행 취소·다시 실행, 검색, 확대·축소, 페이지 이동과 PDF 재열기 후 저장 상태를 확인합니다. 복사 검사는 가상 이벤트로 PDF 텍스트 변환을 검사하며 운영체제의 공용 클립보드를 사용하지 않습니다.

**자동 Zotero 검사 환경에는 아래의 다른 플러그인을 설치하지 않았습니다.** 여백 노트의 독립 동작과 검사에 포함된 기본 리더 동작을 확인한 것이며, 다른 플러그인 조합의 호환성 인증은 아닙니다.

## 지원 범위와 미검증 영역

- 선언한 지원 버전은 Zotero **9.0–9.0.\***이며 실제 검증 기준은 **9.0.6**입니다.
- PDF 리더에만 적용합니다. EPUB와 웹 스냅샷은 건너뜁니다.
- 로컬·CI 실제 Zotero 검사는 macOS에서 실행했습니다. Windows와 Linux는 이 검사에 포함하지 않았습니다.
- PDF 리더의 내부 주석·화면 위치 API를 사용하고 텍스트 초점 처리 함수를 일시적으로 확장합니다. 같은 내부 함수나 PDF 리더 스타일을 바꾸는 다른 플러그인은 조합별 확인이 필요합니다. 특정 플러그인과 함수 래퍼가 겹치는 경우의 자동 검사는 아직 없습니다.

상호작용 문제가 발생하면 Zotero 버전, 여백 노트 버전, 다른 플러그인 이름·버전과 재현 절차를 [이슈](https://github.com/junhwan26/zotero-margin-notes/issues/new)에 적어 주세요. 여백 노트를 끈 상태에서도 문제가 발생하는지 함께 적으면 원인을 확인하는 데 도움이 됩니다.

## 검사 재현

```sh
npm test
npm run check
npm run build
npm run test:native
```

실제 Zotero 검사 도구는 자체 프로필·라이브러리·합성 PDF를 생성하고 정리합니다. 사용자의 기존 라이브러리를 검사하거나 사용자 프로필의 다른 플러그인을 가져와 설치하지 않습니다. 옵션과 CI 설정은 [runtime-test-notes.md](runtime-test-notes.md)를 참고하세요.
