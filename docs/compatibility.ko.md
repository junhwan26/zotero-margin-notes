# 의존성·호환성 검사 기록

[English](compatibility.md)

**확인 날짜: 2026-10-28 · 여백 노트 0.4.2 · Zotero 9.0.6 / 10.0.6 매트릭스 · macOS**

여백 노트는 Zotero 9.0부터 10.0.*까지 지원하도록 선언합니다. **다른 Zotero 플러그인이나 npm 런타임 패키지를 요구하지 않습니다.** 구현은 배포 XPI에 포함되어 있고 코멘트는 Zotero 주석에 저장합니다.

이 문서는 의존성 확인과 독립된 macOS 프로필의 0.4.2 검증을 기록합니다. 이전 검증과 플러그인 활성화 관찰은 날짜가 표시된 과거 기록으로 유지합니다. 함께 활성화되어 있다는 사실만으로 다른 플러그인의 모든 기능을 검사했다고 볼 수는 없습니다.

## 0.4.2 코드 정리 검사

미사용 번역·혼잡도 상태, 중복 카드 라벨 초기화, 코드 블록 정규식의 반복 생성을 정리했습니다. 코멘트 저장과 기본 편집기의 주석 선택은 Zotero 창의 복제 기능을 직접 사용하며, 기능이 없거나 실패하면 원본 권한 배열을 전달하지 않고 오류를 기록합니다. 종료 정리는 원래 오류를 남긴 뒤 다음 정리와 화면 요소 제거를 계속합니다. 화면, 고정 글자 크기, 화면에 맞는 배치, 저장된 주석 코멘트는 유지합니다. 의존성은 추가하지 않았습니다.

| 검사 | 0.4.2 결과 | 확인 범위 |
| --- | --- | --- |
| Node 검사 | **56 / 56 통과** | 배치 20개, 마크다운 18개, 시작/종료·창 간 전달 12개, 다국어 6개. |
| Zotero 9.0.6 실제 회귀 검사 | **294/294개 통과** | 독립된 macOS 실제 앱에서 종료 오류 기록과 나머지 정리 실행을 포함해 검사. |
| Zotero 10.0.6 실제 회귀 검사 | **311/311개 통과** | 같은 검사와 제어된 읽기 모드 검사를 포함. |
| 배포 파일 | **SHA-256 기록** | `zotero-margin-notes-0.4.2.xpi`: `a0d05f1a8bae8888989fed738d15ba2488a6226b62779700b95c18fe1b8a2b43`. |

[0.4.2 공개 검사 요약](evidence/compatibility-0.4.2.json)은 개인 경로, 합성 문장 원문, 로그 없이 실제 앱 검사 605개의 정확한 이름·결과와 파일 해시를 기록합니다. 코드를 바꾸기 전 0.4.1 기준 검사는 Node 49개와 실제 앱 검사 292/309개를 통과했습니다. 새 오류 경로 검사는 복제 기능이 없을 때 저장 성공으로 처리되는 문제를 먼저 재현했으며, 원본 배열 우회 경로 제거 후 통과했습니다. 대체 경로의 분류, 유지한 호환 처리와 검증 범위는 [정리 보고서](cleanup-0.4.2.md)에 기록했습니다.

## 과거 0.4.1 카드 너비 검사 — 2026-10-26

여백 노트 0.4.1은 글자 크기를 늘리지 않고 남은 바깥 여백 전체를 사용해, 공간이 넓어지면 한 줄에 더 많은 단어를 표시합니다. 배치 전에 주석 카드를 왼쪽과 오른쪽의 실제 너비로 각각 측정하므로 여백이 비대칭이어도 알맞은 카드 높이를 사용합니다. 너비가 바뀌어도 편집창 초점, 편집창에서 선택한 텍스트, 저장 전 초안을 보존합니다. 의존성은 추가하지 않았습니다.

| 검사 | 0.4.1 결과 | 확인 범위 |
| --- | --- | --- |
| Node 검사 | **49 / 49 통과** | 기존 마크다운·배치·시작/종료·다국어 검사와 화면에 맞는 너비·좌우 높이별 배치 회귀 검사. |
| Zotero 9.0.6 실제 회귀 검사 | **292 / 292 통과** | macOS 최종 독립 실제 앱 검사. 너비에 맞는 줄바꿈, 글자 크기 유지, 안전한 배치, 편집 초안·초점·선택 영역 보존을 포함합니다. |
| Zotero 10.0.6 실제 회귀 검사 | **309 / 309 통과** | 같은 범위와 제어된 읽기 모드 검사 17개를 추가로 포함합니다. |
| 배포 파일 | **SHA-256 기록** | `zotero-margin-notes-0.4.1.xpi`: `6183a1aefafc68766516b49b361d6af4136a37304497c699dd7dcf61fc726ec5`. |

두 Zotero 버전 모두 글자 크기를 13px로 유지하면서 같은 합성 문단을 180px 카드의 여섯 줄에서 340px 카드의 세 줄로 다시 배치했습니다. [0.4.1 공개 검사 요약](evidence/compatibility-0.4.1.json)은 개인 경로, 합성 문장 원문, 실행 로그 없이 정확한 실제 앱 검사 이름·결과와 파일 해시를 기록합니다. 이 독립 검사는 다른 플러그인 조합이나 사용자의 설치 화면을 인증하는 결과가 아닙니다.

## 과거 0.4.0 검사 — 2026-10-26

여백 노트 0.4.0은 저장된 주석 코멘트를 바꾸지 않고 여백 카드와 추가 코멘트 목록에 마크다운을 표시합니다. 제목, 강조, 목록, 작업 표시, 인용문, 표, 코드, 링크를 지원합니다. 더블클릭하면 원본 마크다운을 수정하며, 저장·취소, 기본 사이드바 동기화, 다시 열기 후 저장 상태도 검사합니다.

| 검사 | 0.4.0 결과 | 확인 범위 |
| --- | --- | --- |
| Node 검사 | **44 / 44 통과** | 문법, 안전한 URL, 비활성 HTML·이미지, 코드 원문, 기존 서식 호환, 큰 입력, 스크립트 로딩을 다루는 마크다운 검사 18개와 기존 배치·시작/종료·다국어 검사. |
| 문법 검사, diff 검사, XPI 빌드 | **통과** | JavaScript 문법, diff 공백 검사, 0.4.0 XPI 패키징. |
| Zotero 9.0.6 실제 회귀 검사 | **271 / 271 통과** | macOS의 Zotero 9.0.6, 합성 두 단 PDF, 임시 프로필과 별도 검사 라이브러리. |
| Zotero 10.0.6 실제 회귀 검사 | **288 / 288 통과** | 같은 독립 검사 환경의 Zotero 10.0.6. 읽기 모드 검사 17개를 추가로 포함합니다. |
| 마크다운 수정과 동기화 | **통과** | 카드·추가 목록의 서식 표시, 정확한 원본 편집, 저장·취소, 사이드바·캐시·SQLite 동기화, 표시 텍스트의 선택 보존, PDF 재열기 후 원본 마크다운 보존. |
| 마크다운 안전 처리와 기본 기능 보존 | **통과** | PDF 화면을 이동하지 않는 안전한 외부 링크 열기, 이미지·HTML·위험한 URL의 비활성 표시, 기존 서식과 섞인 코드 속 HTML 원문 보존, 기존 리더 회귀 검사. |
| 배포 파일 | **SHA-256 기록** | `zotero-margin-notes-0.4.0.xpi`: `9282e7e44152982c840f4132cc1de747e93e662ac6756f8f17f7025b88419d8c`. |

링크는 `http`, `https`, `mailto`를 허용하며 Zotero의 외부 URL 열기 기능을 사용합니다. 이미지는 글자 그대로 표시하고 임의 HTML을 실행하지 않습니다. 기존 Zotero 서식 태그는 기본 편집기 연결과 호환 표시 변환을 유지하며, 마크다운 코드 속 HTML은 원문 그대로 남습니다. 마크다운 패키지나 다른 런타임 의존성은 추가하지 않았습니다. 간단한 마크다운 문법을 지원하며 전체 CommonMark 규격이나 수식 표기는 지원하지 않습니다.

[0.4.0 공개 검사 요약](evidence/compatibility-0.4.0.json)은 정확한 버전, 파일 해시, 완료된 실제 앱 검사 이름과 결과를 기록합니다. 개인 프로필 경로, 라이브러리 내용, 실행 로그는 제외합니다. 위 결과는 독립 환경의 실제 앱 검사이며, 사용자에게 설치된 마크다운 화면의 스크린샷 검토나 다른 플러그인 조합의 새 통합 검사는 아닙니다.

## 의존성 확인

| 구성 요소 | 사용에 필요한가? | 근거 |
| --- | --- | --- |
| Zotero 9.0-10.0.* | 필요 | [지원 버전 선언](../manifest.json). CI는 Zotero 9.0.6과 10.0.6으로 구성되어 있습니다. |
| 다른 Zotero 플러그인 | 불필요 | [manifest](../manifest.json)와 [bootstrap](../bootstrap.js)에 필수 플러그인 선언이나 로딩이 없습니다. |
| npm 런타임 패키지 | 불필요 | [package.json](../package.json)에 런타임 의존성이 없으며 [빌드](../scripts/build.py)는 프로젝트 소스를 묶습니다. |
| Node.js·Python 3 | 개발에만 필요 | 검사와 XPI 생성에 사용합니다. 사용자는 XPI를 바로 설치합니다. |

bootstrap은 포함된 언어·배치·마크다운·표시 스크립트를 불러오고, 타이머는 Zotero의 Gecko 내장 모듈을 사용합니다. 코멘트를 표시하거나 편집하기 위해 별도 외부 서비스를 이용할 필요는 없습니다. Zotero의 일반 주석 동기화와 GitHub 플러그인 업데이트는 사용할 수 있습니다.

Zotero 공식 [Zotero 10 for Developers](https://www.zotero.org/support/dev/zotero_10_for_developers) 문서는 호환성을 확인한 뒤 `strict_max_version`을 `10.0.*`로 올리라고 안내합니다. Zotero [버전 기록](https://www.zotero.org/support/changelog)은 Zotero 10.0.6이 2026-10-07에 릴리스되었다고 기록합니다.

여백 노트 0.3.1은 여백 카드 표시 대상을 하이라이트와 밑줄 주석에서 Zotero 메모 주석까지 확장합니다. 메모 주석에는 선택된 원문 인용문이 없으므로 카드는 빈 인용문 영역을 숨기고 주석 코멘트만 표시합니다.

실제 Zotero 검사는 텍스트 선택 팝업, 하이라이트, 밑줄, Zotero 메모 주석, 사이드바·여백 코멘트 편집, 더블클릭, 블록 선택 표시, 두 테마의 흰색 노트, 삭제, 실행 취소·다시 실행, 검색, 확대·축소, 페이지 이동과 PDF 재열기 후 저장 상태를 확인합니다. 복사 검사는 가상 이벤트로 PDF 텍스트 변환을 검사하며 운영체제의 공용 클립보드를 사용하지 않습니다.

**자동 Zotero 검사 환경에는 아래의 다른 플러그인을 설치하지 않았습니다.** 여백 노트의 독립 동작과 검사에 포함된 기본 리더 동작을 확인한 것이며, 다른 플러그인 조합의 호환성 인증은 아닙니다.

## 과거 다른 플러그인과 함께 활성화된 환경

2026-10-08 실제 Zotero 10.0.6 UI에서 여백 노트 0.3.1이 활성화된 상태로 아래 버전을 확인했습니다. **과거 설치·활성화 상태 관찰**이며, 개별 플러그인의 전체 기능을 검사한 결과는 아닙니다. 이 조합을 0.4.0, 0.4.1, 0.4.2에서 다시 검사하지 않았습니다.

| Translate for Zotero | 2.4.8 | 여백 노트 0.3.1과 함께 활성화됨. 전체 기능 검사는 수행하지 않았습니다. | 아니요 |

2026-10-07 Zotero 9.0.6 시기 관찰 기록: Better BibTeX 9.0.70, Translate for Zotero 2.4.8, Ethereal Style 6.0.86, Research Vault Bridge 0.2.0은 여백 노트 0.2.3과 함께 활성화되어 있었고, ZotMoov 1.2.32는 설치되어 있었지만 비활성 상태였습니다. 이 기록은 Zotero 10 호환성으로 재분류하지 않습니다.

## 지원 범위와 미검증 영역

- 선언한 지원 버전은 Zotero **9.0-10.0.\***이며 자동 검사 버전은 **9.0.6**과 **10.0.6**입니다.
- PDF 리더에만 적용합니다. EPUB와 웹 스냅샷은 건너뜁니다.
- 로컬 실제 Zotero 검사는 macOS에서 실행했습니다. Windows와 Linux는 이 검사에 포함하지 않았습니다.
- Zotero 10 읽기 모드는 PDF iframe을 읽기 화면 아래에 유지합니다. Margin Notes는 해당 화면을 멈춰서 카드가 읽기 모드를 가리지 않게 하고, Fit Notes가 숨은 PDF 화면을 확대/축소하지 않게 합니다. 자동 회귀 검사는 실제 PDF 리더의 읽기 모드 상태와 PDF 화면의 표시 여부를 통해 이 동작을 확인하며, 별도 읽기 모드 화면 전체를 조작하는 검사는 아닙니다.
- 과거 0.3.1의 실제 설치 PDF 메모 카드 표시는 스크린샷 도구를 사용할 수 없어 macOS 접근성 상태로 확인했습니다. 스크린샷이나 픽셀 단위 시각 검증은 하지 않았습니다. 독립 실제 앱 검사 결과는 사용자 환경의 설치나 현재 화면의 스크린샷 검토를 뜻하지 않습니다.
- PDF 리더의 내부 주석·화면 위치 API를 사용하고 텍스트 초점 처리 함수를 일시적으로 확장합니다. 같은 내부 함수나 PDF 리더 스타일을 바꾸는 다른 플러그인은 조합별 확인이 필요합니다. 특정 플러그인과 함수 래퍼가 겹치는 경우의 자동 검사는 아직 없습니다.

상호작용 문제가 발생하면 Zotero 버전, 여백 노트 버전, 다른 플러그인 이름·버전, 읽기 모드 활성 여부와 재현 절차를 [이슈](https://github.com/junhwan26/zotero-margin-notes/issues/new)에 적어 주세요. 여백 노트를 끈 상태에서도 문제가 발생하는지 함께 적으면 원인을 확인하는 데 도움이 됩니다.

## 개발 검사

```sh
npm test
npm run check
npm run build
```

실제 Zotero 검사 도구는 자체 프로필·라이브러리·합성 PDF를 생성하고 정리합니다. 사용자의 기존 라이브러리를 검사하거나 사용자 프로필의 다른 플러그인을 가져와 설치하지 않습니다. CI는 공식 Zotero DMG를 내려받고 SHA-256을 확인한 뒤 Zotero 9.0.6과 Zotero 10.0.6 각각에서 실제 앱 검사를 한 번씩 실행합니다. 설정 세부 내용은 [runtime-test-notes.md](runtime-test-notes.md)를 참고하세요.
